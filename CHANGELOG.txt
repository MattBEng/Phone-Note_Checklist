- Widget categories are now tappable. Tap a category name in the widget and

===========================================
2026-09-14 (b)
===========================================
- Added auto-update checking. Every time you open the main Checklist app
  screen, it quietly asks GitHub if a newer build exists. If so, a banner
  appears at the top: "Update available (vXX)" with an Update button.
  Tapping it downloads the new APK and opens Android's install screen -
  you still tap "Install" yourself (Android doesn't allow silent installs
  outside the Play Store, this gets you as close as possible: one tap).
- The very first time you use this, Android may instead send you to a
  settings screen to allow "install unknown apps" for the Checklist app
  specifically. Turn that on, then tap Update again.
- Files changed: app/build.gradle.kts, AndroidManifest.xml, MainActivity.kt
- File added: app/src/main/kotlin/com/mattbrady/checklist/update/UpdateChecker.kt
- IMPORTANT - one manual step needed: I can't edit the GitHub Actions
  workflow file directly (it's protected), so you need to paste an updated
  version of .github/workflows/build-apk.yml yourself. See the chat message
  for the exact content to paste in. Without this step, every build will
  still show up as "v1" and the update banner will never appear.
