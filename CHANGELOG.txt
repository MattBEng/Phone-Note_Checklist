2026-09-15 (g)
===========================================
- Found the REAL reason the widget kept showing old categories (Boat,
  Fishing, Garden) mixed in with new ones, and why deleting something in
  the app didn't clear it from the widget: the app was never actually
  downloading your existing notes from the server. It only ever showed
  notes created on THIS install since the last time you deleted/reinstalled
  the app. The widget's counts, on the other hand, come straight from the
  server's real category data - so Boat/Fishing/Garden weren't stale or
  fake, they were real leftover items sitting on the server that the app
  itself couldn't see or let you delete. That's why it looked "stuck."
- Fix: every sync now also pulls your full note list down from the server
  into the app, not just pushes new/changed notes up. So old items will
  now actually show up in the app's own list, where you can open and
  delete them like normal - and once deleted, they'll disappear from the
  widget too on the next sync.
- Also found that the tap-to-expand widget feature (added a couple of
  fixes ago) had not actually made it onto your PC's copy of the file -
  it silently reverted back to the plain, non-interactive version at some
  point (this has happened once before with a different file this week;
  cause still unclear, but I now double-check every fix landed before
  moving on). Re-applied it and confirmed it's really there this time.
- Files changed:
  app/src/main/kotlin/com/mattbrady/checklist/widget/ChecklistWidget.kt
  app/src/main/kotlin/com/mattbrady/checklist/data/ChecklistRepository.kt
  app/src/main/kotlin/com/mattbrady/checklist/data/local/NoteDao.kt

- Fixed: widget showing different/old data than the app. The bug: opening
  the app syncs and updates the app's own screen straight away, but it
  never told the widget to redraw itself - only a separate background sync
  did that. So the widget could sit there showing stale content until that
  background sync happened to run, which could be a long wait.

  finishes, not just from the background sync.
- File changed: app/src/main/kotlin/com/mattbrady/checklist/data/ChecklistRepository.kt
- After installing this build: open the app once (to sync), then remove
  the widget and add it back fresh one more time to clear out whatever
  stale content it's currently showing. From then on it should stay in
  sync automatically.

2026-09-14 (d)
===========================================
- Fixed the "have to delete the app every time" problem. The real cause:
  every GitHub Actions build was happening on a fresh throwaway machine with
  no saved signing key, so Gradle silently generated a brand new random
  signing key on every single build. Android refuses to install a new APK
  over an old one if the signing key doesn't match - that's why you were
  always forced to uninstall first. It also would have made the auto-update
  button useless, since in-place updates require the signature to match.
- Fix: added a permanent signing key (app/debug.keystore) and pointed
  build.gradle.kts at it, so every build from now on - yours and GitHub's -
  uses the same key.
- Files changed: app/build.gradle.kts
- File added: app/debug.keystore
