2026-09-14 (d)
===========================================
- Fixed the "have to delete the app every time" problem. The real cause:
  every GitHub Actions build was happening on a fresh throwaway machine with
  no saved signing key, so Gradle silently generated a brand new random
  signing key on every single build. Android refuses to install a new APK
  over an old one if the signing key doesn't match - that's why you were
  always forced to uninstall first. It also would have made the auto-update
  button useless, since in-place updates require the signature to match.
- Fix: added a permanent signing key (app/debug.keystore) and pointed
  build.gradle.kts at it, so every build from now on - yours and GitHub's -
  uses the same key.
- Files changed: app/build.gradle.kts
- File added: app/debug.keystore
- ONE-TIME step needed: because this build's signature is different from
  every earlier build's (each of which used a random one), you'll need to
  uninstall the app ONE more time before installing the next build. After
  that, every future build should update in place - no more uninstalling.
- Also: if the widget shows old data or doesn't respond to taps after an
  update, remove it from your home screen and add it again fresh - that
  makes it reconnect to the currently installed app.

2026-09-14 (b)
===========================================
- Added auto-update checking. Every time you open the main Checklist app
  screen, it quietly asks GitHub if a newer build exists. If so, a banner
  appears at the top: "Update available (vXX)" with an Update button.
  Tapping it downloads the new APK and opens Android's install screen -
  you still tap "Install" yourself (Android doesn't allow silent installs
  outside the Play Store, this gets you as close as possible: one tap).
- The very first time you use this, Android may instead send you to a
  settings screen to allow "install unknown apps" for the Checklist app
  specifically. Turn that on, then tap Update again.
- Files changed: app/build.gradle.kts, AndroidManifest.xml, MainActivity.kt
- File added: app/src/main/kotlin/com/mattbrady/checklist/update/UpdateChecker.kt
- Needed a manual paste into .github/workflows/build-apk.yml (protected
